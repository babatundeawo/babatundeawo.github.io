# Security policy

This is a static website with no accounts, forms or stored user data. If you believe you have found a security problem, such as a leaked secret, a script-injection issue or a malicious link, please report it privately instead of opening a public issue.

Email [babatundeawoyemi91@gmail.com](mailto:babatundeawoyemi91@gmail.com) with the page address, what you found and how to reproduce it. You will get a reply as soon as possible.
