# Assets

Static files used by the pages.

- `fonts/`: self-hosted web fonts (WOFF2) and their licences.
- `icons/`: favicon, Apple touch icon and web-app icons (192, 512 and maskable).
- `images/`: the portrait in AVIF, WebP and JPEG sizes (`babatunde.jpg` is the original), and the social preview image `og-image.png`.
- `screenshots/`: real screenshots of the site, listed in `manifest.webmanifest` for the install dialog.
