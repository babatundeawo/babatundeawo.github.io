# Fonts

Self-hosted web fonts (Latin subset, WOFF2).

- `fraunces-latin-600.woff2`: Fraunces SemiBold, used for headings. Licence: `OFL-Fraunces.txt`.
- `inter-latin-regular.woff2`, `inter-latin-medium.woff2`, `inter-latin-semibold.woff2`: Inter, used for body text. Licence: `OFL-Inter.txt`.

Both families are licensed under the SIL Open Font License 1.1.
