# Fonts

Self-hosted web fonts used by the site (Latin subset).

- `fraunces-latin-600.woff2`: Fraunces SemiBold, used for headings. Licence: `OFL-Fraunces.txt`.
- `inter-latin-*.woff`: Inter Regular, Medium and SemiBold, used for body text. Inter is licensed under the SIL Open Font License 1.1 (copyright The Inter Project Authors, https://github.com/rsms/inter).
